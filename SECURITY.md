# Security

Please report security problems privately, not in a public issue.

- **GitHub:** open the repository's Security tab and choose "Report a vulnerability".
- **Email:** contact@anshuljain.net

Include what you found, how to reproduce it, and what it affects. You'll get a reply within a few days.

The live demos on kopialens.com and anshuljain.net run this code. Please don't run load tests against them or try to run up their AI costs.
